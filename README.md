# hello-Piau

Este repositório é um laboratório para aprender e praticar os principais recursos do GitHub. Use-o para experimentar em projetos de teste, sem colocar dados pessoais, tokens ou outros segredos nos commits.

## Roteiro de aprendizagem

Faça os exercícios em ordem ou escolha um tema para praticar:

1. **Repositórios e arquivos** — explore o histórico, edite este README, crie arquivos e observe as alterações na aba **Code**.
2. **Git e branches** — crie uma branch, faça alterações em commits pequenos e compare-a com a branch padrão.
3. **Issues e planejamento** — abra uma issue com uma tarefa, adicione rótulos e acompanhe o trabalho em um projeto.
4. **Pull requests** — abra um pull request da sua branch, descreva a mudança, revise o diff, deixe comentários e faça merge.
5. **Colaboração** — pratique revisões, menções e discussões. Combine com colaboradores antes de alterar configurações ou permissões do repositório.
6. **GitHub Actions** — crie um workflow em `.github/workflows/` e observe suas execuções na aba **Actions**. Comece com um workflow de verificação simples.
7. **Publicação** — crie uma tag e um release de teste para aprender a registrar versões.
8. **Configurações e segurança** — explore páginas de configuração, permissões e recursos de segurança sem desativar proteções nem publicar credenciais.

## Como praticar

- Faça cada exercício em uma branch própria e abra um pull request, mesmo quando estiver trabalhando sozinho.
- Use issues para registrar o objetivo e marque-as como concluídas ao terminar.
- Leia as mensagens de erro e os logs de Actions; registre o que aprendeu na descrição do pull request ou em uma issue.
- Para desfazer uma experiência, reverta o commit ou feche o pull request de teste.
- Não use dados reais ou segredos. Se um exercício exigir credenciais, use um ambiente de teste e os **GitHub Actions secrets**; nunca grave valores secretos em arquivos ou logs.

## Próximo passo

Escolha um exercício do roteiro, abra uma issue descrevendo o que quer aprender e pratique o fluxo completo: branch, commit, pull request, revisão e merge.
